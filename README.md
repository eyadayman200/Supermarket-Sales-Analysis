# Supermarket Sales Analysis

## Overview
This project analyzes supermarket sales transactions to identify sales trends, customer behavior, branch performance, and product profitability using Excel and Power BI.

## Dataset
The dataset contains sales transactions from three supermarket branches.

Main columns include:
- Invoice ID
- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Tax
- Total Sales
- Gross Income
- Gross Margin Percentage
- Date
- Time
- Payment Method
- Rating

---

## Objectives

- Analyze overall sales performance.
- Compare branch performance.
- Evaluate product line profitability.
- Understand customer purchasing behavior.
- Build an interactive dashboard.
